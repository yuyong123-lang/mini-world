## 波末集成冒烟检查（每波 commit 前主线程必做）

1. `npx tsc --noEmit` 全项目零错误
2. `npm test` 全量绿
3. `npm run dev` 浏览器打开无 console 报错
4. 当前里程碑验收清单（各任务卡内有）逐项勾选
5. git status 无越权文件改动（对照 conventions.md §14 所有权表）

## 契约变更流程

实现中发现接口缺陷 → 该 Agent 停止，报告问题 → 主线程修订 interfaces.md → 重发受影响任务。
禁止任何 Agent 私改契约或他人文件。

## 里程碑验收冻结标准

- **M1**：60fps；走跳不穿墙不卡缝；挖放即时反馈；同 seed 刷新地形一致
- **M2**：徒手→LOG→木板→工作台→木镐→石镐石剑全链路；持续奔跑 60s 无 >100ms 卡顿；区块加载无缝
- **M3**：F5 后地形改动/背包/时间/位置精确恢复；饥饿→饿伤→进食→再生数值通路有效；一昼夜翻转正确
- **M4**：夜晚 2 分钟内遇怪被追击并可反杀；杀猪吃肉回血闭环；实体满额帧率 >55fps
- **M5**：冷启动到可操作 <10s；10 分钟游玩内存平稳；workersOff 降级开关仍可玩

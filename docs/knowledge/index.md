# 项目文档中心

> 本文档为项目文档的总入口；具体业务文档请进入对应层级与子目录查阅。

## 知识分层结构

本项目文档按三层架构组织，上层可引用下层，禁止反向依赖。

| 层级 | 目录 | 职责 |
|------|------|------|
| 项目层 | [01-项目层](./01-项目层/) | 业务方向、核心流程、架构设计、决策记录 |
| 技术层 | [02-技术层](./02-技术层/) | 中间件配置、数据库设计、编码规范、第三方库、接口文档 |
| 资产层 | [03-资产层](./03-资产层/) | 产品需求、技术方案、测试用例、Bug记录 |
| 原始层 | [04-原始层](./04-原始层/) | 会议纪要、聊天记录、网页等未提炼的原始材料 |

> **原始层说明**：原始层不属于三层结构，是正式文档的**信息源头**。材料经提炼后才能进入三层。详见 [04-原始层/README.md](./04-原始层/README.md)。

## 本项目特有约定

- 文档编号格式 `DOC-{层级编码}-{子目录序号}-{3位序号}`；迁移的历史文档（架构文档、任务卡等）**保留原文件名**，编号登记在 YAML 头部
- 多 Agent 波次化开发产生的 41 张任务卡归档于 [03-资产层/02-技术方案](./03-资产层/02-技术方案/)，保留 w0~w11 波次子目录
- README（仓库根）引用本库的路径均以 `docs/knowledge/` 为前缀

## 维护规范

- 目录名使用中文，中划线分隔，数字前缀排序
- 文档格式统一使用 Markdown，所有文档必须包含 YAML 头部元数据
- 每个目录必须配套 `index.md` 索引文件
- 原始层目录配套 `README.md` 作为层说明（不是 `index.md`）
- 新增文档请参考各层 `index.md` 中的归档指引与文档清单

# 原始层

> 本目录存放**未经过结构化提炼的原始资料**（会议纪要、聊天记录、网页、转写、草稿等），作为三层结构（项目层 / 技术层 / 资产层）的信息源头。原始材料经提炼后才能进入正式层级。

## 归档范围

本目录用于归档：

- 会议纪要（视频会议、线下讨论的记录或转写）
- 客户/用户访谈记录
- 网页资料、行业报告、竞品分析截图
- 聊天记录（群聊、1v1 中的关键讨论）
- 录音/录像转写、白板照片
- 邮件、需求工单、临时草稿

**不属于**本目录：

- 已整理成正式文档的内容（→ 归档到 `docs/knowledge/01-项目层/`、`02-技术层/`、`03-资产层/` 对应子目录）
- 代码注释、API 文档（→ 三层结构）

## 子目录结构（按来源类型）

| 子目录 | 用途 | 何时使用 |
|--------|------|----------|
| `01-会议记录/` | 会议纪要 | 团队例会、评审会、需求讨论等高频会议 |
| `02-网页资料/` | 网页资料 | 行业报告、竞品分析、技术文章收藏 |
| `03-聊天记录/` | 聊天记录 | 群聊、1v1 中需要追溯的关键讨论 |
| `04-录音转写/` | 录音/录像转写 | 会议录像、访谈音频转写 |
| `05-其他杂项/` | 其他杂项 | 临时草稿、邮件、工单截图等 |

## 文件命名规范

采用 **`YYYY-MM-DD-{来源}-{简短描述}.md`** 格式，来源简码：`meeting` / `web` / `chat` / `transcript` / `misc`。完整示例：

- `2026-09-03-meeting-34省区域规划讨论.md`
- `2026-08-20-web-体素引擎AO算法调研.md`
- `2026-08-15-chat-建筑stamp拆分讨论.md`

> 该规范用于**指导 AI 与作者为新材料正确命名**，不强制历史材料改名。

## 与三层结构的关系

```
原始层（本目录）───(提炼)──>  资产层 / 技术层 / 项目层
    │                              ▲
    └─────(引用追溯)────────────────┘
```

提炼流程：识别主题 → 抽取要点 → 写入正式文档（带完整 YAML 头部）→ 登记索引 → 记录原始出处。

## AI 强制约束

- **不要**为原始层文件生成 YAML 头部或 `index.md`
- **不要**把原始材料直接复制粘贴到三层结构中
- 当用户提供本目录下的原始材料并要求"整理成文档"时，必须按提炼流程生成新的正式文档
